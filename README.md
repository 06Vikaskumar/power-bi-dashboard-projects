# Stock Market Power BI Dashboard

# Project Overview
This project is an interactive Stock Market Analysis Dashboard created using Microsoft Power BI.

#  Objectives
- Analyze stock price trends
- Track market performance
- Analyze trading volume
- Compare stock returns
- Display important KPIs
- Provide interactive data visualizations

# Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Stock Market Dataset

# Dashboard Features
- Stock Price Analysis
- Market Trend Analysis
- Trading Volume
- Returns Analysis
- Interactive Filters
- KPI Cards
- Charts and Graphs

- `project minor 1/` – Power BI project files
- `project minor 2/` – Power BI project files
